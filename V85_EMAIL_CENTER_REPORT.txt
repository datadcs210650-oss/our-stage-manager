BUSINESS ACTION SAFETY
- Registration/Fund business state is written before email step.
- Email failure cannot falsely roll back or undo the business action.
- Admin always has “Không gửi”.
- Imported results never automatically generate/send email.
- Recipient list is explicitly selectable.

SECURITY REVIEW
- RESEND_API_KEY only server env.
- RESEND_WEBHOOK_SECRET only server env.
- Firebase ID token required for /api/email-center Admin actions.
- Role restricted to Admin/Super Admin server-side.
- Template output HTML-escaped; no arbitrary Admin HTML is injected into outgoing email.
- Recipient/variable lengths bounded.
- One queue document per recipient to isolate delivery status and retries.
- Webhook event log stores recipient hash rather than raw recipient.
- Source scan must show no private key/API key before deploy.

KNOWN PRODUCT LIMITS
- Resend API scheduling is limited to 30 days ahead, therefore reminders farther away should remain Draft/Queue until within that window.
- Email Center deliberately does not auto-send from import/background result processing.
- Queue UI keeps only the newest 200 rows in the current Admin view; Firestore retains older rows unless separately cleaned up.
